The Sixth Edition C Compiler with a commentary on its source

In 1975 the C compiler that shipped with Unix was about nine thousand lines of code, written by Dennis Ritchie, and it was small enough to read in a week. This book reads it with you. It follows the pattern of John Lions’ famous commentary on the Sixth Edition kernel: the complete source, numbered line by line, and alongside it a commentary that explains how each part works and why it was written that way.

Source: Research Unix V6, /usr/source/c, July 1975 · Commentary written in 2026

Commentary

How to read this book

Numbers in the commentary such as 1534 are line numbers in the listing. Click one and the listing opens beside the text at that line, so you can read the code and the explanation together. Hold Ctrl or ⌘ to open the full listing page instead.

All compiler output in the book is real. It was produced by running the original 1975 binaries of cc, c0, c1 and c2 on a simulated PDP-11/40. The repository holds the scripts that did it.

Several chapters contain small working models of parts of the compiler: the lexer, the expression parser, the type encoding, the switch generator. They are written in JavaScript and follow the original code closely, so you can feed them your own input and watch each step.
