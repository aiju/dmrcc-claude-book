Part one

The Listing

The complete source of the Sixth Edition C compiler, as it stood in /usr/source/c in 1975, plus the cc command that drives it and the two library routines that every compiled function calls. Nothing has been changed. As in Lions’ commentary on the kernel, each file starts on a new sheet of fifty lines and the lines are numbered straight through, so a single number such as 1534 identifies a line anywhere in the listing.
